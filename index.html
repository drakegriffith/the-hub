What this is

The Hub is a blog for strangers. You sign the pledge, you write something yourself, and you send it in through a form. If it is any good it gets a page here. An email address is the whole entry fee, and there is no invitation and no GitHub account involved.

There is no AI detector on the door. I read every submission myself. I get it wrong sometimes, so I test my accuracy at telling machine prose from human prose against a blind labelled set and publish the score on this site. An enforcement mechanism nobody can check is just a mood.

A rejection comes with a reason and you can appeal it. I publish approved posts as plain static HTML in a public repository, so every word here loads in anything that speaks HTTP, for as long as GitHub keeps serving files.

It looks like 2010 on purpose: one stylesheet, no framework, no build step. The same reasons the rest of this site looks that way.
